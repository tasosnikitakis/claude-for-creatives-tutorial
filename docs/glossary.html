Reference

Glossary

Developer terms as a designer needs them. Each entry says what the thing is and what it is for in this tutorial.

Claude

Agent / agentic loop
An AI that plans, acts (edits files, runs commands), checks its results and repeats. Claude Code is one. You direct it at the plan and the result.
Artifact
A live output beside a chat in the Claude app: a document, a piece of code, a design. Something you keep and edit rather than read once.
Claude Design
A design canvas inside artifacts. Conversation on one side, editable visuals on the other. For concepts, decks, prototypes.
Claude Code
Anthropic's agent for working in a real project: it reads and edits files, runs commands, and talks to tools like Figma and GitHub. In this tutorial you use it in the Code tab of the Claude desktop app.
CLAUDE.md
The project brief Claude Code reads at the start of every session. Keep it short and specific.
Context window
Everything the model can see at once in a session. As it fills, quality drops. /clear empties it.
Hook
A small script that runs automatically at a set moment, such as after every edit. Guaranteed to run, unlike an instruction.
MCP (Model Context Protocol)
The standard way Claude connects to other tools: Figma, Notion, GitHub. The Figma MCP server lets Claude read designs and send code back to the canvas.
Plan mode
A state where Claude Code reads and proposes but changes nothing. Your concept review. Chosen in the mode selector under the prompt box.
Plugin
An installable bundle of skills, hooks and MCP connections. Anthropic's frontend-design plugin is the one to install first.
Project
A workspace in the Claude app with knowledge files and instructions that every conversation inside it can use. One per client.
Skill
A short instruction file Claude loads when it is relevant or when you invoke it by name. Your brand voice, your workflows.
Subagent
A specialist helper with its own instructions and limited tools. A read-only reviewer is the typical one.

Design context

Design tokens
Named design values — colours, type sizes, spacing — used in code. The vocabulary that keeps a system consistent.
DESIGN.md
A file that lists the tokens with a sentence on what each is for, so an AI tool uses them correctly. A format Google Labs published in 2026.
UX.md
NN/g's proposed companion file: research findings, interaction standards, glossary, user models. What a new designer would need to be told.
Heuristics (Nielsen's ten)
A classic usability checklist: visibility of system status, user control, consistency, error prevention, and so on. The usability row of the rubric.
WCAG 2.2 AA
The accessibility standard most organisations target: contrast, text alternatives, keyboard access, focus visibility.
Vibe coding / vibe design
Building by describing intent and accepting what the AI produces, often without reading the code. Fine for throwaway exploration; not a process.

Tooling

Code tab / session
The part of the Claude desktop app where Claude Code works. Each conversation there is a session, attached to one folder on your computer.
Changes panel
The desktop app's view of every edit Claude made, line by line. You can comment on any line.
Browser pane
A preview inside the desktop app where your page opens and where Claude takes screenshots to check its work.
Mode selector
The control under the prompt box: Manual, Accept edits, Plan, Auto. It decides how much Claude does before asking you.
Command / CLI / terminal
A typed instruction to the computer, and the text window developers type them in. Claude runs commands for you and, in Manual mode, shows each one first; you never need to open a terminal yourself.
GitHub CLI (gh)
A small program you install once so Claude can create repositories and publish on GitHub for you.
Repository (repo)
A project folder with its full history, tracked by Git.
Commit
A saved snapshot of the project with a message saying what changed and why.
Push
Uploading your commits to GitHub.
Branch
A parallel copy of the project for trying something without touching the main version.
Pull request
A proposal to merge a branch into the main version, with a place to review and discuss it.
Diff
The exact before-and-after of a change. What you read before approving.
GitHub Pages
Free hosting of a folder in your repository as a public website. How this site is published.
localhost / local preview
A version of the site running on your own computer, at an address like http://localhost:3000, for checking before you publish.
npm / Node.js
Tools for running JavaScript and installing packages. Many web projects use them; Claude Code's installer does not need them.
HTML / CSS / Tailwind / React
The language of page structure; the language of its styling; a popular shortcut for writing CSS; a library for building interfaces from components. You will read these, not write them.
