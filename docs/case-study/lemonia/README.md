# Lemonia Bakehouse — starter folder

A worked example for the "Claude for creatives" tutorial. Lemonia Bakehouse
is a **fictional** client: the business, the people, the interviews and the
reviews are all invented for practice. Use them freely; do not present any of
them as real.

## What is in here

| File | What it is | First used in stage |
|---|---|---|
| `brief.md` | The client brief, as the owner wrote it | 1 |
| `research/interviews.md` | Notes from six short customer conversations | 1 |
| `research/reviews.md` | Twenty customer comments collected from cards and messages | 1 |
| `brand/voice-samples.md` | Five pieces of approved writing to reverse-engineer the voice from | 2 |
| `content/glossary-el.md` | Agreed English → Greek terms for the bakery | 2 |
| `content/menu.md` | The menu, prices and allergens, in English and Greek | 3 |
| `brand/brand-notes.md` | What the client already has: colours, type, photography, logo notes | 3 |
| `runbooks/review-rubric.md` | The scoring sheet; runbooks/ stays outside the published docs/ folder | 5 |
| `.claude/agents/ux-reviewer.md`, `.claude/agents/editorial-qa.md` | Read-only reviewer helpers | 6 |
| `.claude/skills/new-page/SKILL.md` | The gated page-building workflow | 8 |

Folders starting with a dot (`.claude`) may be hidden on your computer. That is normal; Claude can see them.

## How to use it

1. Download the zip from the tutorial's worked-example page and unzip it into a folder called `lemonia`.
2. For Modules 1–2: create a Project in the Claude app called "Lemonia Bakehouse" and add every file as knowledge.
3. For Modules 3 onward: open a Code session in the Claude desktop app on the `lemonia` folder.
4. Follow the stages on the worked-example page. Each stage names the files it uses and the prompt to run.

By the end the folder will also contain your `CLAUDE.md`, `DESIGN.md`,
`UX.md`, a brand-voice skill, a microcopy matrix, the site in `docs/`, and a
runbook in `runbooks/`. That finished folder is what a client handover looks like.
