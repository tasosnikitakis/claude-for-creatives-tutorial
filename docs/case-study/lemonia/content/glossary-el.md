## Transcreation notes

- "Because bakers need the sea too" → "γιατί και οι φούρναρηδες θέλουν
  θάλασσα" (owner's own line; keep it).
- "If something has run out, it is because it was good" → owner's Greek in
  voice-samples.md is the agreed version.
- English understatement can read as cold in Greek. Add warmth with the
  owner's name or "σας περιμένουμε" rather than exclamation marks.
