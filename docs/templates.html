The CLAUDE.md this site uses

# Project
Tutorial site "Claude for creatives": static HTML in docs/, published with
GitHub Pages from the main branch and the /docs folder. No build step.

# Commands
- Preview: `npx serve docs` (or VS Code Live Preview on docs/index.html)
- Check:   `npx html-validate "docs/**/*.html"`

# Design rules
- IMPORTANT: use tokens from @DESIGN.md only; never invent colour, type or spacing values.
- IMPORTANT: all copy follows the brand-voice skill. Sentence case. No exclamation marks.
- IMPORTANT: every page works at 390px and 1440px; every image has meaningful alt text; contrast meets WCAG AA.
- Links inside the site are relative (assets/style.css, ../index.html), never absolute.
- Keep one memorable element per page (the prompt panels); everything else quiet.

# Art direction
Editorial and calm. Generous whitespace. Fraunces for headings, Source Sans 3
for text. One blue accent, used for links and prompt panels only. Left-aligned.
No cards-for-everything, no gradients, no all-caps labels, no arrows on links.

# Workflow
- Plan before changes that touch more than one file.
- Show screenshots as evidence before saying a visual change is done.
- Run the ux-reviewer subagent on any new or changed page before committing.
- Commit after each approved change with a message that says what changed and why.

The brand-voice skill this site uses

---
name: brand-voice
description: Apply the "Claude for creatives" voice to any text on the tutorial site — lessons, prompts, labels, errors, README.
---
Audience: one experienced creative director, new to developer tooling. Address her as "you".

Voice: plain, warm, confident. Explain, never sell. Respect her expertise;
explain the tooling, not the craft.

Tone by context:
- Lesson prose: direct, concrete, example before abstraction.
- Cautions: calm, factual, one sentence on what to do.
- Checkpoints: short, testable statements.
- Prompts: written as she would say them to a colleague; specific nouns, a check at the end.

Terminology: "Claude app", "Claude Design", "Claude Code"; "skill", "subagent", "hook";
"repository" (not "repo" on first use); "commit", "push". Avoid "leverage", "unlock", "supercharge", "seamless".

Hard rules: sentence case everywhere. No exclamation marks. No all-caps labels.
No "simply" or "just". Under 25 words per sentence where possible. British spelling.

Before returning copy: check it against these rules and the length of the element it goes in.
