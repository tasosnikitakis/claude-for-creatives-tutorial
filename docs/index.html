A tutorial in ten modules

Claude for creatives

How a creative director uses Claude and Claude Code to design, write and ship UI/UX and content work — without becoming a developer first.

You already know how to brief a team, judge a layout, hear when copy is off-key and tell a good idea from a safe one. That is the hard part. This tutorial teaches the rest: how to put that judgement into files Claude reads, how to direct Claude Design and Claude Code the way you would direct a studio, and how to review what comes back.

The central idea, which you will meet again in every module: context files and review checklists come before code. Your brand-voice skill, your design tokens and your review rubric are the reusable business assets. The pages Claude generates from them are disposable.

How to use this tutorial

  • Work the modules in order. Each one builds on files you made in the one before.
  • Every module has objectives, a short lesson, a hands-on exercise, prompts you can copy, and a checkpoint you must pass before moving on.
  • Spend about two weeks in Modules 0–2 (the Claude app and Claude Design) before you open your first Code session in Module 3. Your strengths compound first; the tooling comes second.
  • Keep a notes file as you go. Every time a prompt works well, save it. That file becomes your prompt library in Module 8.

What you need

  • A Claude Pro plan or higher. Claude Code is not on the Free plan. Pricing and plan contents change — check claude.com/pricing.
  • From Module 3: the Claude desktop app on your computer and a free GitHub account. Everything happens in the desktop app; there is no code editor or terminal to learn.
  • From Module 7 (optional): a Figma account. Reading designs works on any plan; writing back to the canvas needs a Full seat.
  • Five pieces of your own best writing and one recent project to use as raw material.

The modules

  1. Orientation: the new creative stack

    What has changed in the field, where Claude fits, and the one idea everything else rests on.

  2. Claude as creative partner: Projects and skills

    Build a Project around your brand, then reverse-engineer a voice guide into a reusable skill.

  3. Claude Design: prompt to prototype

    Goal, layout, content, audience. Iterate on the canvas, export, and hand off to code.

  4. Your studio in the desktop app

    The Code tab of the Claude desktop app, and the few Git words you need to direct it.

  5. Claude Code fundamentals

    The agentic loop, plan mode, permission modes, screenshots and evidence.

  6. Context engineering

    CLAUDE.md, DESIGN.md, UX.md and the art-direction block that stops generic output.

  7. Content systems in Claude Code

    A microcopy matrix, an editorial-QA helper and a Greek localisation workflow.

  8. Figma round-trip with MCP

    Read a frame into code; send a coded page back to the canvas.

  9. Automated workflows and publishing

    Reviewer subagents, hooks, a /new-page skill, and GitHub Pages.

  10. Capstone: the studio playbook

    Run a full mini-project and write the runbook your studio will reuse.

Worked example

Lemonia Bakehouse is a fictional bakehouse-café that needs a bilingual website. Its starter folder holds a brief, brand notes, voice samples, customer research, a menu and a Greek glossary, and the page walks it through every module from brief to handover. Use it alongside the modules, or as your capstone if you do not have a real project to hand.
