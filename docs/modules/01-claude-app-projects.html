Claude as creative partner: Projects and skills

Build a Project around your brand, then turn five pieces of your best writing into a voice guide Claude applies automatically.

By the end of this module you can

  • Set up a Claude Project with the right knowledge files and instructions for a client or product.
  • Run a research-synthesis conversation that cites its evidence and admits its uncertainty.
  • Reverse-engineer a voice-and-tone guide from real samples and package it as a skill.

Projects: one workspace per client

A Project is a workspace whose knowledge files and instructions are available to every conversation inside it. Create one per client or product and add: the brand book, the voice guide (once you have written it, below), research summaries, a glossary of terms the client uses, and anything you find yourself re-explaining. Write project instructions the way you would brief a new hire: short, specific, with the non-negotiables first. One line that pays for itself immediately: "Always say which source a claim comes from."

Two habits make Projects work. Keep the knowledge files current — a stale brand book is worse than none, because Claude will apply it confidently. And start a fresh conversation for each distinct task; long, wandering chats degrade.

Research synthesis you can trust

Claude is good at finding patterns in transcripts, survey exports and support tickets. It is also capable of landing on the wrong takeaway with full confidence, which is why the prompt below demands quotes, flags outliers and asks for the model's own doubt. You verify every theme against the raw quotes before it goes into a deck.

A voice guide that actually gets used

Most voice guides fail because they are lists of adjectives. "Warm but professional" means nothing to a model and little to a writer. The method that works — adapted from how content agencies now do it — is to reverse-engineer the guide from examples:

  1. Collect about five pieces you consider gold-standard for this brand. Mixed formats are fine: a landing page, an email, an error message, a social post.
  2. Give Claude a one- or two-page template to fill (voice principles, tone by context, terminology, reading level, do/don't examples).
  3. Make the tone rules conditional: "if the user has just hit an error, be calm and name the next step; never apologise, never blame."
  4. Add hard rules a model can check: sentence case for buttons, no exclamation marks in errors, forbidden words, length limits.
  5. Turn the result into a skill — a short instruction file with a one-line description of when to apply it. Skills load automatically when they are relevant, in the Claude app and later in Claude Code, so the guide becomes mandatory context rather than optional reading.

Then rewrite the result as a Claude skill: a short file with a name, a one-line description that says when to apply it, and the rules in the order a writer would check them.

Exercise: Project plus skill

  1. Create a Project for one real client or for the family business. Add the brand book and a glossary. Write instructions of no more than ten lines.
  2. Run the voice prompt on five real samples. Edit the output hard: cut anything you would not say to a writer in a briefing.
  3. Save the result as a skill. Test it: in a new conversation, ask for a 40-word error message and a 120-word welcome email without mentioning the voice. Both should sound like the brand.
  4. If one does not, the skill is missing a rule. Add it. This loop — generate, judge, fix the rule — is the whole discipline of this tutorial.

Checkpoint

  • A Project exists with at least three knowledge files and short instructions.
  • Your brand-voice skill produces on-brand copy for two different states without being reminded.
  • You have run a synthesis prompt on real material and checked every theme against its quotes.
