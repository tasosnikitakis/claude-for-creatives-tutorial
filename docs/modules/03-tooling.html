Developer tooling without fear

VS Code, the terminal and Git, reduced to what a designer directing Claude Code actually needs. Claude will type most of it; you need to know what it means.

By the end of this module you can

  • Install VS Code, the Claude Code command-line tool and the Claude Code extension.
  • Explain a repository, a commit, a push, a branch and a pull request in one sentence each.
  • Create a GitHub repository and get your first commit into it, with Claude doing the typing.

Three tools, one picture

VS Code is a text editor that shows a project as a folder of files. You will mostly use it to read what Claude wrote and to see the preview. The terminal is a text box where you type commands; it lives inside VS Code and Claude Code uses it on your behalf. Git keeps the history of the project — every saved snapshot, who made it, and why — and GitHub is where that history is stored online and published from.

If you have used version history in Figma or Google Docs, you already understand Git's purpose. The vocabulary is the only new part:

WordMeaningDesign-world equivalent
Repository (repo)The project folder plus its full historyThe project file, with every version kept
CommitA saved snapshot with a message saying what changed"Save version: hero copy revised"
PushUpload your commits to GitHubSyncing to the shared drive
BranchA parallel copy for trying something without touching the main versionDuplicating a page to explore a direction
Pull requestA proposal to merge a branch into the main version, with a place to review itPresenting a direction for approval
DiffThe exact before-and-after of a changeComparing two versions side by side

Installing everything

  1. Confirm your Claude plan is Pro or higher. Claude Code is not available on the Free plan.
  2. Install VS Code from code.visualstudio.com.
  3. Install the Claude Code command-line tool. Open the Terminal app (macOS) or PowerShell (Windows) and paste one line: 
    # macOS / Linux
curl -fsSL https://claude.ai/install.sh | bash

# Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex
    No other software is needed; the installer brings its own.
  4. In VS Code open the Extensions panel (Ctrl/Cmd+Shift+X), search for "Claude Code" by Anthropic, and install it. The extension gives you a Claude panel beside your files.
  5. Create a folder on your computer called hello-studio. In VS Code choose File → Open Folder, open it, and click "Trust" when asked.
  6. Click the Claude icon in the sidebar and sign in with your Claude account.
  7. Create a free account at github.com. Then install the GitHub command-line tool (gh) from cli.github.com and run gh auth login once in the terminal, following the prompts. This lets Claude create repositories and publish for you.

Installation steps change. If something here does not match what you see, the official VS Code guide is current; this page is not guaranteed to be.

Let Claude teach you the terminal

You do not have to memorise commands. You have to be able to read them. The fastest way to learn is to ask Claude Code to narrate everything it does, in plain language, as it does it.

Prompt: first repository

I am a designer and new to the terminal. Explain every command you run in one plain sentence before you run it. Then: initialise a Git repository in this folder, create a README.md that says what this project is, make the first commit with a clear message, create a private GitHub repository called hello-studio, and push to it. Tell me the repository's web address when you are done.

Prompt: understanding what happened

Show me the commit history as a short list. Then explain what a branch is using this repository as the example, and create one called try-new-headline. Do not change any files yet.

Exercise: hello studio

  1. Complete the installation list. Take your time; this is the only module where the obstacles are mechanical rather than creative.
  2. Run the first-repository prompt. Read every narrated sentence. When one does not make sense, ask Claude to rephrase it — in the same session, before moving on.
  3. Open your repository on github.com and find the README. You have published a file to the internet via the terminal. That is the whole mechanism; everything later is the same mechanism with better content.
  4. Ask Claude to change one word in the README, commit and push again. Watch the diff in VS Code's Source Control panel before you approve.

Checkpoint

  • VS Code opens your folder, the Claude panel is signed in, and claude runs in the integrated terminal.
  • A private repository exists on GitHub with at least two commits.
  • You can explain commit, push and branch without looking at the table.
